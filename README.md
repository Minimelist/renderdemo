# Task Manager - Full Stack Deployment Test

A complete task management application demonstrating deployment of a full-stack application with PostgreSQL, React, Node.js, and Python on Render.

## Architecture

- **Frontend**: React.js (Static Site on Render)
- **Backend APIs**: 
  - Node.js/Express - Task CRUD operations
  - Python/Flask - Analytics and logging
- **Database**: PostgreSQL (Managed on Render)

## Local Development

### Prerequisites
- Node.js (v14+)
- Python (3.8+)
- PostgreSQL
